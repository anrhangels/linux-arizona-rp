# Техническое руководство

Здесь собраны параметры установщика, устройство окружения и ручная диагностика. Если нужна обычная установка без дополнительных настроек, используйте [пошаговый маршрут](installation.md).

## Быстрый старт через Git

```bash
git clone https://github.com/anrhangels/linux-arizona-rp.git
cd linux-arizona-rp
bash install.sh --plan
bash install.sh
```

`install.sh` — точка входа для системных зависимостей. `scripts/install.py` — пользовательская часть: загрузки, префикс, шрифты, конфигурация и ярлыки. Запуск Python-файла напрямую не устанавливает системные пакеты.

## Параметры установщика

| Параметр | Действие |
|---|---|
| `--plan` | Показать действия без изменений и сетевых запросов |
| `--yes` | Не спрашивать подтверждение плана и системных пакетов; аутентификация `sudo` сохраняется |
| `--no-system-packages` | Пропустить установку системных зависимостей; они уже должны быть готовы |
| `--prefix DIR` | Выбрать префикс вместо `~/Games/arizona-rp/prefix` |
| `--installer FILE` | Использовать свой официальный EXE; принимаются полный путь или имя файла в папке загрузок |
| `--installer auto` | Найти самый свежий Arizona EXE в папках загрузок |
| `--windows-fonts DIR` | Импортировать известные файлы Segoe из вашей папки Windows Fonts |
| `--fonts-only` | Настроить шрифты для уже установленного в выбранном префиксе лаунчера |
| `--no-hud` | Пропустить установку и настройку MangoHud в этом запуске |
| `--restore MANIFEST` | Восстановить файлы по напечатанному при настройке плану |
| `--help` | Показать справку |

`--no-hud` не удаляет HUD, который уже был настроен раньше. Для возврата прежних настроек используйте резервную копию. `--yes` также не выбирает игру, сервер и аккаунт в лаунчере.

Пример установки в отдельную папку без HUD:

```bash
bash install.sh --prefix "$HOME/Games/arizona-custom/prefix" --no-hud
```

Автоматическое подтверждение для заранее подготовленного окружения:

```bash
bash install.sh --no-system-packages --yes
```

## Префиксы и существующая запись Faugus

Стандартный префикс — `~/Games/arizona-rp/prefix`. Он должен находиться внутри домашней папки. Сам путь префикса не может быть символической ссылкой. Непустая посторонняя папка без Arizona не используется автоматически.

Если запись с ID `arizona-launcher` уже указывает на другой префикс, установщик остановится и покажет его путь. Передайте этот путь явно через `--prefix`, если хотите работать с существующей установкой. Записи других игр сохраняются.

После прерванной установки можно повторить ту же команду. Префикс, созданный этим установщиком, отмечается `.linux-arizona-rp-managed`; это позволяет продолжить его подготовку. Существующий исправный лаунчер не переустанавливается при каждом запуске скрипта.

Импорт шрифтов в готовую установку:

```bash
bash install.sh --fonts-only --prefix "$HOME/Faugus/arizona" \
  --windows-fonts "/путь/к/Windows/Fonts"
```

Последний путь — пример: замените его реальным. [Имена поддерживаемых файлов →](fonts.md#оригинальные-шрифты-segoe)

## Источники загрузок

Для новой установки скрипт запрашивает актуальный официальный выпуск лаунчера и проверяет SHA-256 его EXE. Номер выпуска не зашит в инструкцию. Установленный лаунчер обновляется своими средствами.

GE-Proton, UMU и файл Noto закреплены в `configs/downloads.json`. Для EXE, UMU и архива Proton проверяется SHA-256; для Noto — размер и Git blob ID закреплённого исходника. Частичная загрузка хранится как `.part` и не запускается. При несовпадении проверки установщик останавливается.

Для явно выбранного локального `--installer FILE` проверяется сигнатура Windows EXE, но опубликованная сумма автоматически не сверяется. Такой файл выбирает сам пользователь с [официального сайта Arizona](https://arizona-rp.com/).

При изменении официальной схемы загрузки, отсутствии суммы или сетевой ошибке нет автоматического перехода на неизвестные зеркала. [Источники компонентов →](sources.md)

## Пути и XDG

| Данные | Расположение по умолчанию |
|---|---|
| Игровой префикс | `~/Games/arizona-rp/prefix` |
| GE-Proton, UMU, копия инструментов и HUD | `~/.local/share/linux-arizona-rp/` |
| Кэш загрузок | `~/.cache/linux-arizona-rp/` |
| Логи и резервные копии | `~/.local/state/linux-arizona-rp/` |
| Пользовательские шрифты | `~/.local/share/fonts/linux-arizona-rp/` |
| Команда запуска | `~/.local/bin/arizona` |
| Ярлык | `~/.local/share/applications/linux-arizona-rp.desktop` |
| Записи Faugus | `~/.var/app/io.github.Faugus.faugus-launcher/data/faugus-launcher/games.json` |

Учитываются XDG_DATA_HOME, XDG_STATE_HOME, XDG_CACHE_HOME и XDG_CONFIG_HOME. При переопределении используйте абсолютные пути. При восстановлении цели файлов должны оставаться внутри домашней папки.

Список папок загрузок берётся из `user-dirs.dirs`; дополнительно проверяются `~/Downloads` и `~/Загрузки`. Конфиг читается как данные, а не выполняется оболочкой. В обычном автоматическом режиме папки браузерных загрузок не используются.

## Запуск и блокировки

Команда `arizona` запускает копию инструментов, сохранённую отдельно от скачанного репозитория. Для установки, восстановления и обычного запуска используется файловая блокировка; параллельные операции этим инструментом не допускаются.

Изменение шрифтов требует закрытых Faugus и Wine-приложений. Процессы принудительно не завершаются. Проверка консервативная: она может попросить закрыть Wine-программу из другого префикса.

При запуске через скрипт Flatpak получает доступ к выбранному префиксу и доступ на чтение к runner и настройкам HUD. Эти разрешения передаются команде запуска, а не записываются как глобальное разрешение на всю домашнюю папку.

## Диагностика

Из любого каталога после установки:

```bash
~/.local/bin/arizona --check
```

Из папки скачанного репозитория:

```bash
python3 scripts/samp_linux.py doctor
python3 scripts/samp_linux.py list
bash scripts/arizona.sh check
```

`doctor` выводит краткую информацию о системе. `list` показывает записи Faugus и их ID. `check` проверяет Flatpak, EXE, префикс, установленный runner и UMU. Наличие файлов не подтверждает доступность сервера, работоспособность аккаунта, античита или голоса.

Если ID записи отличается от `arizona-launcher`, команды помощника принимают его явно:

```bash
bash scripts/arizona.sh check --game ваш-id
bash scripts/arizona.sh launch --game ваш-id
```

Замените `ваш-id` значением из `list`. Установщик и команда `arizona` используют стандартный ID.

## MangoHud

Установщик определяет ветку VulkanLayer по runtime Faugus и устанавливает соответствующее расширение. Затем подготавливает локальные библиотеки и манифесты для запуска через Flatpak/UMU.

| Клавиша | Действие |
|---|---|
| F10 | Минимальный → подробный → скрытый режим |
| F12 | Показать или скрыть панель |
| Левый Shift + F4 | Перечитать конфигурацию |

Ограничение FPS не задаётся. Часть датчиков может быть недоступна внутри контейнера. После обновления расширения MangoHud повторите настройку при закрытом Faugus:

```bash
bash scripts/arizona.sh hud
```

Если расширение отсутствует, помощник покажет нужную команду его установки. Скрипт `hud` не является установщиком системных зависимостей.

## Восстановление файлов

Путь `restore.json` печатается при настройке. Закройте Faugus и Wine-приложения и подставьте реальный путь:

```bash
bash install.sh --restore "$HOME/.local/state/linux-arizona-rp/backups/ДАТА/restore.json"
```

`ДАТА` — имя конкретной папки резервной копии, а не буквальная часть команды. Найти созданные планы можно так:

```bash
find "$HOME/.local/state/linux-arizona-rp/backups" -name restore.json -print
```

При изменённом XDG_STATE_HOME используйте соответствующий путь состояния.

Снимок содержит предыдущие версии изменяемых файлов; для новых файлов записывается, что до настройки их не было. Восстановление возвращает прежние файлы и удаляет созданные из этого плана. Режим исполняемых файлов сохраняется.

**Границы:** это восстановление файлов, а не удаление игры. Системные пакеты, Flatpak, скачанные компоненты и игровой префикс остаются. Полные копии реестра и `games.json` возвращают состояние на момент снимка: если позднее вы добавили другие игры или поменяли настройки, сначала сохраните новые данные.

Для точечного восстановления служебных файлов шрифтов есть отдельный `restore-fonts`. [Команды и порядок действий →](fonts.md#служебные-файлы-рядом-со-шрифтами)

## Разработка и проверки

```bash
python3 -m unittest discover -s tests -v
bash -n install.sh scripts/arizona.sh
bash install.sh --plan
```

Тесты работают на временных данных. Они не устанавливают игру, не выполняют системный пакетный менеджер и не заменяют реальную игровую проверку. В CI те же проверки выполняются на Python 3.10, 3.12 и 3.14.

Изменение `assets/create_art.py` относится только к иллюстрациям; для их перерисовки нужен pycairo, для установки игры он не требуется. [Правила оформления →](design-system.md)
