# Дистрибутивы и зависимости

Игровое окружение общее: **Flatpak → Faugus → UMU → Proton**. Отличается системная подготовка. Не нужны отдельные DEB/RPM с игрой: `install.sh` сам выбирает пакетный менеджер и запускает общую часть.

| Семейство | Пакеты |
|---|---|
| Arch, CachyOS, Manjaro, EndeavourOS | `python flatpak fontconfig ttf-dejavu vulkan-tools ca-certificates` |
| Debian, Ubuntu, Linux Mint, Pop!_OS | `python3 flatpak fontconfig fonts-dejavu-core vulkan-tools ca-certificates` |
| Fedora Workstation | `python3 flatpak fontconfig dejavu-sans-fonts vulkan-tools ca-certificates` |
| openSUSE Tumbleweed | `python3 flatpak fontconfig dejavu-fonts vulkan-tools ca-certificates` |

Профиль определяется по `ID` и `ID_LIKE` в `/etc/os-release`. При неизвестной ОС автоматическая системная часть остановится с сообщением. Скрипт не переключает системную оболочку, не меняет рабочий стол и не правит настройки мониторов.

Noto Color Emoji загружается отдельно из закреплённого официального исходника: дистрибутивы могут поставлять разные форматы цветного шрифта. Например, в Fedora пакет использует COLRv1, а наша подготовка выбирает CBDT-файл для воспроизводимого набора. Проверяются размер и контрольный идентификатор файла. Оригинальные Segoe доступны только при выборе вашей папки шрифтов.

## Драйвер и Vulkan

Драйвер GPU должен быть установлен средствами вашего дистрибутива. После установки системных инструментов можно проверить:

```bash
vulkaninfo --summary
```

Успешный вывод на хосте не заменяет проверку игры внутри Flatpak. Runtime Faugus подтягивает свои зависимости и расширения; для NVIDIA согласуйте версию драйвера хоста и Flatpak. После обновления драйвера выполните `flatpak update`, перезагрузитесь при необходимости и повторите запуск. Универсальная автоматическая замена драйвера здесь не выполняется.

## Неизменяемые системы и ручная подготовка

Fedora Silverblue / Kinoite, SteamOS, NixOS и другие подобные системы не заявлены как прошедшие игровую проверку. Если есть `/run/ostree-booted`, установщик не пытается выполнять обычный `dnf install`.

Подготовьте средствами вашей ОС Python 3.10+, Flatpak, Fontconfig, DejaVu Sans и Vulkan, затем:

```bash
bash install.sh --no-system-packages
```

На старых выпусках проверьте Python: нужен `tarfile.data_filter`, доступный в Python 3.12+ и в актуальных исправленных сборках 3.10/3.11. Скрипт не распаковывает Proton небезопасным обходным способом. ARM и старые неподдерживаемые выпуски дистрибутивов не входят в эту поставку.

## Что означает поддержка

Команды пакетных менеджеров и логика установщика подготовлены для четырёх семейств. Игровой результат пока подтверждён на Arch; для остальных нужны отдельные реальные проверки. Результаты не подменяются наличием соответствующей ветки в скрипте.
