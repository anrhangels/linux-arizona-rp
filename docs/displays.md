# Внешний монитор, разрешение и 165 Гц

Проверено 7 ноября 2026 на Arch Linux с Hyprland/Xwayland, экраном ноутбука 2560×1600 (масштаб 1,6) и внешним HDMI-монитором 1920×1080. После выбора внешнего экрана и включения поддерживаемого режима 165 Гц пользователь подтвердил работу игры.

## В списке нет 1920×1080

Если игра показывает только `Default` и разрешения до 1600×1000, она может получать режимы экрана ноутбука с учётом масштаба. Название `Default` само по себе не позволяет выбрать физический экран.

1. Закройте игру и официальный лаунчер.
2. В терминале посмотрите выходы:

   ```bash
   xrandr --listmonitors
   ```

3. Найдите подключённый внешний экран. В нашей проверке это `HDMI-A-3`; у вас имя может отличаться.
4. Запустите Arizona с явным выбором этого выхода:

   ```bash
   ~/.local/bin/arizona --monitor HDMI-A-3
   ```

5. Вновь откройте выбор разрешения в игре. Ранее открытый список может содержать закэшированные режимы.

Параметр `--monitor` появился в этом обновлении. Для старого установленного ярлыка сначала [обновите локальные инструменты](advanced.md#обновление-инструментов).

Команда делает выбранный подключённый выход основным для **текущей сессии X11/Xwayland**. Это общая настройка X11, её могут учитывать другие X11-программы. Она не меняет расположение, разрешение, масштаб, частоту, конфигурацию Hyprland и не сохраняет выбор после выхода из сессии. При новом запуске передавайте параметр снова. При отключённом мониторе скрипт остановится с понятным сообщением; без параметра он не переключает экраны.

Без обновления инструмента можно один раз выполнить эквивалентную команду, подставив имя своего подключённого выхода:

```bash
xrandr --output HDMI-A-3 --primary
```

Потом перезапустите игру/лаунчер. Для возврата выберите прежний подключённый выход той же командой, например `xrandr --output eDP-1 --primary`. Исходно основной выход мог быть вообще не назначен.

## Нужны именно 165 Гц

Сначала включите нужную частоту для внешнего экрана в настройках Linux. Режим `preferred` иногда выбирает 60 Гц, даже если монитор поддерживает больше. Используйте только режимы, которые сообщает система для конкретного монитора и подключения.

Для Hyprland:

```bash
hyprctl -j monitors
```

Проверьте `name`, `width`, `height`, `refreshRate` и `availableModes`. В нашей проверке `HDMI-A-3` сообщал `1920x1080@165.00Hz`, но работал при 60 Гц. После настройки реальное значение стало около **165,002 Гц**. Небольшое отличие от круглого числа нормально; Xwayland может показывать, например, 164,83 Гц.

### Hyprland с Lua-конфигурацией

Сделайте резервную копию своего файла конфигурации. В существующем блоке **именно внешнего монитора** измените только `mode`, сохраняя свои `position` и `scale`:

```lua
hl.monitor({
    output   = "HDMI-A-3",       -- замените именем своего выхода
    mode     = "1920x1080@165", -- только если такой режим поддерживается
    position = "-1920x0",      -- пример: сохраните своё расположение
    scale    = "auto",         -- сохраните своё значение
})
```

Затем:

```bash
hyprctl reload
hyprctl configerrors
hyprctl -j monitors
```

Не создавайте второй противоречащий блок для того же выхода. При проблеме восстановите резервную копию и повторите reload. Путь к конфигурации зависит от установки; в нашей использовался `~/.config/hypr/hyprland.lua`.

В старых версиях Hyprland используется `hyprland.conf` с другим синтаксисом. В новых Lua-версиях команда `hyprctl keyword monitor ...` может отвечать `unknown request`; в таком случае используйте конфигурацию своей версии, а не случайные команды из старых инструкций. Другие окружения рабочего стола настраивайте через их параметры экранов.

После изменения частоты полностью перезапустите игру и лаунчер, затем выберите **1920×1080 @ 165**. Скрипт автоматически не повышает частоту: поддержка режима зависит от монитора, кабеля, порта и драйвера. Частота монитора и FPS игры проверяются отдельно.
