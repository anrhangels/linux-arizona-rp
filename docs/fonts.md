# Русский текст и эмодзи

## Нужно ли что-то устанавливать вручную

**При обычной установке — нет.** Скрипт добавляет шрифты для русского текста и эмодзи. Сначала установите и запустите игру по [основной инструкции](installation.md).

В нашей игровой установке ошибки загрузки шрифтов удалось убрать, эмодзи отображались в игровых диалогах, а кириллица появилась и в голосовом интерфейсе. Эти результаты подтверждены пользователем. Передача речи через микрофон проверяется отдельно от отображения подписей.

Если текст читается правильно, дополнительные действия на этой странице не нужны.

## Если вместо букв квадраты или вопросы

1. Полностью закройте игру и лаунчер.
2. Откройте игру снова через **Arizona RP** в меню или команду `~/.local/bin/arizona`.
3. Проверьте тот же диалог: русский текст, буквы «Я», «ё», «й» и используемые в нём эмодзи.
4. Если проблема осталась, можно подключить оригинальные шрифты Segoe из своей Windows — порядок ниже.

В исходной настройке использовалось несколько шрифтов и изменений. Свободный набор нового установщика ещё нужно проверить на чистой установке; одинаковый результат на всех системах не заявлен.

## Оригинальные шрифты Segoe

Этот способ нужен только при проблемах с текстом или если вы хотите использовать оригинальные Microsoft-шрифты. Скрипт не включает их в репозиторий: они берутся из вашей собственной Windows.

Найдите папку `Windows/Fonts` на своём Windows-разделе или подготовьте отдельную папку с нужными файлами:

| Файл | Что это |
|---|---|
| `segoeui.ttf` | Основной шрифт Segoe UI |
| `seguisb.ttf` | Полужирный Segoe UI Semibold |
| `seguiemj.ttf` или `SegoeUIEmoji.ttf` | Шрифт эмодзи Segoe UI Emoji |

Названия распознаются без учёта регистра. Если этих файлов у вас нет, не подставляйте вместо них случайные файлы с похожими именами.

### Во время новой установки

Из папки репозитория:

```bash
bash install.sh --windows-fonts "/путь/к/Windows/Fonts"
```

**Замените `/путь/к/Windows/Fonts` реальным путём к вашей папке.** Кавычки оставьте.

### Когда игра уже установлена

Закройте игру, лаунчер, Faugus и другие Windows-приложения. Если использовалось стандартное расположение новой установки:

```bash
bash install.sh --fonts-only --prefix "$HOME/Games/arizona-rp/prefix" \
  --windows-fonts "/путь/к/Windows/Fonts"
```

Первую строку и продолжение можно скопировать вместе. Последний путь обязательно замените своим. Если игра находится в другой папке-префиксе, её путь также нужно указать вместо стандартного. Что такое префикс, объяснено в [словаре](glossary.md).

**Ожидаемый результат:** сообщение об установленных шрифтах и путь к резервной копии. После этого снова откройте игру и проверьте текст.

## Служебные файлы рядом со шрифтами

В нашей установке встречалась другая причина ошибок: рядом с настоящим шрифтом `font.ttf` лежал отдельный служебный файл `font.ttf:Zone.Identifier`. Игра пыталась прочитать его как шрифт.

Обычная команда `arizona` проверяет такие файлы перед запуском и при необходимости переносит их в резервную копию. Настоящие `.ttf` и `.otf` сохраняются.

Для ручной проверки из папки репозитория:

```bash
bash scripts/arizona.sh fix-fonts
```

**Это только просмотр:** скрипт покажет найденные файлы. Если их нет, исправлять здесь нечего.

Чтобы применить исправление, сначала закройте игру, лаунчер, Faugus и Wine-приложения, затем выполните:

```bash
bash scripts/arizona.sh fix-fonts --apply
```

Сохраните напечатанный путь `restore.json` — он нужен для возврата перемещённых файлов. Команда восстановления:

```bash
bash scripts/arizona.sh restore-fonts --manifest "/полный/путь/к/restore.json"
```

Замените пример точным путём из сообщения. Если после создания копии лаунчер уже восстановил такой же файл, помощник не будет перезаписывать его автоматически.

## Для опытных пользователей

- DejaVu Sans берётся из системного пакета. Noto Color Emoji загружается из закреплённого официального исходника с проверкой содержимого.
- Шрифты копируются в `drive_c/windows/Fonts` выбранного префикса и в пользовательскую папку шрифтов Linux.
- Установщик регистрирует семейства в реестре этого префикса. Для отсутствующих Segoe создаются Wine-подстановки на свободные семейства.
- При импорте оригинального Segoe ранее созданная нами соответствующая подстановка снимается; неизвестные пользовательские подстановки автоматически не удаляются.
- Точечное исправление переносит только обычные файлы `:Zone.Identifier` рядом с существующими `.ttf`/`.otf`; символические ссылки пропускаются.
- После обновления клиента служебные файлы могут появиться снова. На один запуск можно пропустить их обработку: `~/.local/bin/arizona --no-font-repair`.

После восстановления пользовательских шрифтов при необходимости обновите кэш Linux командой `fc-cache -f` и перезапустите приложения. [Общий откат настроек →](advanced.md#восстановление-файлов)


## Вопросительные знаки в меню AZRTC

7 ноября 2026 в новом префиксе обнаружен отдельный случай: русский игровой чат и основной интерфейс работают, а подписи в меню голосового чата AZRTC 0.9.28 отображаются как `????`. Это не подтверждает отсутствие кириллицы во всей игре. Причина (кодировка/локаль/конкретный шрифт модуля) пока исследуется; исправление для нового префикса не объявляется проверенным.

Не переустанавливайте весь клиент и не заменяйте все шрифты случайными файлами. Для работы с реестром/шрифтами нужно сначала закрыть игру и лаунчер и сохранить резервную копию префикса. Результат проверки этого конкретного случая будет добавлен после воспроизведения и подтверждения.
