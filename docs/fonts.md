# Шрифты, кириллица и эмодзи

## Подтверждённый результат

В исходной настройке удалось убрать ошибки загрузки шрифтов. Эмодзи отображались в игровых CEF-диалогах. Пользователь дополнительно подтвердил: **кириллица в голосовом интерфейсе тоже появилась**. Это обновляет старый отчёт лаборатории, где результат ещё не был подтверждён.

Точный вклад каждого изменения отдельно не измерялся: в работе использовались DejaVu, Segoe UI / Semibold и шрифты эмодзи. На чистом префиксе свободный набор нужно проверить отдельно; он не объявлен точной заменой полного набора Microsoft. Работа подписей в голосовом интерфейсе не доказывает передачу микрофона.

## Что устанавливается автоматически

- **DejaVu Sans** — кириллица и основной текст, берётся из системного пакета.
- **Noto Color Emoji** — закреплённый официальный файл с проверкой содержимого. Копируется в префикс и пользовательскую папку шрифтов Linux.
- Шрифты регистрируются в текущем префиксе. Для отсутствующих Segoe добавляются локальные Wine-подстановки имён на свободные семейства.
- При запуске точечно обрабатываются лишние файлы `:Zone.Identifier` рядом с настоящими `.ttf` / `.otf`.

Настройка не удаляет все шрифты игры и не подменяет DLL голосового модуля.

## Оригинальные Segoe из своей Windows

Из собственной папки `Windows/Fonts` можно передать:

| Имя | Семейство |
|---|---|
| `segoeui.ttf` | Segoe UI |
| `seguisb.ttf` | Segoe UI Semibold |
| `seguiemj.ttf` или `SegoeUIEmoji.ttf` | Segoe UI Emoji |

Названия распознаются без учёта регистра. Импортируются только известные файлы шрифтов с ожидаемым форматом, а не вся папка Windows.

```bash
bash install.sh --windows-fonts "/путь/к/Windows/Fonts"
```

Для готового префикса:

```bash
bash install.sh --fonts-only --prefix "$HOME/путь/к/префиксу" \
  --windows-fonts "/путь/к/Windows/Fonts"
```

Эти файлы не включены в репозиторий и не скачиваются с неофициальных сайтов. Они копируются из вашей локальной установки. Оригинальные имена семейств регистрируются в префиксе; реальные Microsoft-шрифты имеют приоритет над создаваемыми нами свободными подстановками при их наличии на новой настройке.

## Если остаётся прежняя подстановка

Если сначала был установлен свободный набор, а затем добавлен Segoe, удалите только соответствующие значения подстановок в реестре **этого префикса** либо восстановите снимок перед настройкой. При повторном импорте установщик очищает ранее созданные им подстановки для переданных оригинальных семейств. Не очищайте весь реестр Wine.

## Лишние файлы рядом со шрифтами

```bash
bash scripts/arizona.sh fix-fonts
bash scripts/arizona.sh fix-fonts --apply
```

Первая команда только показывает список. Вторая требует закрытых приложений Wine и переносит служебные файлы в резервную папку. Настоящие шрифты остаются на месте. После обновления клиента такие файлы могут появиться снова — поэтому обычная команда `arizona` проверяет их перед запуском.

Откат с напечатанным путём:

```bash
bash scripts/arizona.sh restore-fonts --manifest "/путь/к/резервной/копии/restore.json"
```

Отключить автоматическую проверку при одном запуске:

```bash
~/.local/bin/arizona --no-font-repair
```

## Проверка в игре

1. Откройте диалог с русским текстом, проверьте буквы «Я», «ё», «й».
2. Проверьте эмодзи в том CEF-диалоге, где они используются сервером.
3. Откройте голосовой интерфейс и проверьте подписи.
4. Отдельно проверьте микрофон с другим игроком и серверные требования к уровню.
5. Повторите после закрытия и запуска клиента.

Если установленный шрифт не появился в Linux-приложениях, перезапустите их; после отката обновите кэш командой `fc-cache -f`.
