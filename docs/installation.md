# Установка от начала до первого входа

## Перед началом

Нужны Linux x86_64, Python 3.10+ с исправленным модулем `tarfile`, рабочий графический сеанс и Vulkan-драйвер. Оболочка установит Python и остальные системные зависимости, если запускать `bash install.sh`. Не запускайте весь установщик через `sudo`. Закройте Faugus, игры и приложения Wine: список игр и файлы шрифтов должны быть свободны от параллельного изменения.

Скачайте ZIP репозитория или клонируйте его, откройте терминал в папке проекта и выполните:

```bash
bash install.sh --plan
bash install.sh
```

`--plan` только показывает действия. При обычном запуске скрипт показывает план, спрашивает согласие, а затем пакетный менеджер может запросить пароль. `--yes` пропускает подтверждения плана и пакетного менеджера; пароль `sudo` он не обходит.

Проверка сертификата и контрольных сумм обязательна. Ошибка сети не приводит к запуску неполного или непроверенного файла. Для Proton и UMU используются фиксированные проверяемые сборки; для официального лаунчера ссылка определяется заново при новой установке. Уже установленный лаунчер обновляет себя сам.

## Что происходит автоматически

1. Определяется семейство дистрибутива, устанавливаются зависимости.
2. Подключается пользовательский Flathub и устанавливается Faugus с его runtime.
3. Подготавливаются GE-Proton и UMU. Системный Wine не нужен.
4. Скачивается актуальный официальный установщик Arizona. Загрузка сохраняется в кэш проекта, а не в папку загрузок браузера.
5. Установщик запускается в отдельном префиксе. Если после установки открылся сам лаунчер, закройте его, чтобы настройка продолжилась.
6. Устанавливаются Noto Color Emoji и DejaVu Sans, регистрируются шрифты. Опционально подключаются ваши Segoe UI / Emoji.
7. Создаётся запись Faugus, команда `arizona` и ярлык меню. MangoHud подбирается по установленному runtime.

Первое скачивание Proton и runtime может занимать значительное время. После первой установки Flatpak иногда нужен выход из сеанса и повторный вход, чтобы ярлык появился в меню.

## Первый вход

```bash
~/.local/bin/arizona
```

В официальном лаунчере выберите Arizona RP, скачайте клиент, затем выберите сервер и войдите. Скрипт не проходит регистрацию и не знает ваших учётных данных. При повторном запуске перед входом проверяются служебные файлы шрифтов и создаётся лог.

В нашей установке старая форма авторизации позволила завершить регистрацию: если новая форма принимает текст, но не отправляет его, отключите «Новую авторизацию» в настройках лаунчера. Для передвижения нужна английская раскладка. Чат проверялся с русским текстом.

## Если лаунчер уже скачан

Полный путь может содержать кириллицу и пробелы — заключайте его в кавычки:

```bash
bash install.sh --installer "$HOME/Загрузки/Arizona-Games-Launcher.exe"
```

Можно передать только имя файла: сначала проверяется текущая папка, затем папка загрузок XDG, `~/Downloads` и `~/Загрузки`:

```bash
bash install.sh --installer Arizona-Games-Launcher.exe
```

Или выбрать наиболее свежий Arizona EXE в этих папках:

```bash
bash install.sh --installer auto
```

Ручной EXE берите с [официального сайта Arizona](https://arizona-rp.com/). Для ручного файла опубликованная контрольная сумма автоматически не проверяется: вы явно выбираете свой локальный установщик. Автоматический режим всегда сверяет сумму официального выпуска.

## Свой префикс и существующая игра

По умолчанию: `~/Games/arizona-rp/prefix`. Чтобы выбрать другой:

```bash
bash install.sh --prefix "$HOME/Games/arizona-custom/prefix"
```

Чужой непустой префикс без Arizona не перезаписывается. Если Arizona уже есть в Faugus, но привязана к другому префиксу, установщик сообщит его путь и попросит передать его явно. Чужие записи Faugus сохраняются.

Для существующей игры можно отдельно применить шрифты:

```bash
bash install.sh --fonts-only --prefix "$HOME/Faugus/arizona" \
  --windows-fonts "/путь/к/Windows/Fonts"
```

Для установки без HUD добавьте `--no-hud`. После прерванной установки повторите ту же команду: созданный этим установщиком префикс отмечен служебным файлом. Посторонний префикс без такой отметки не используется автоматически.

## Что хранится на компьютере

| Данные | Каталог по умолчанию |
|---|---|
| Префикс с игрой | `~/Games/arizona-rp/prefix` |
| Runner, UMU, копия инструментов и HUD | `~/.local/share/linux-arizona-rp/` |
| Скачанные компоненты | `~/.cache/linux-arizona-rp/` |
| Логи и резервные копии | `~/.local/state/linux-arizona-rp/` |
| Свободные и выбранные вами шрифты | `~/.local/share/fonts/linux-arizona-rp/` |
| Команда запуска | `~/.local/bin/arizona` |
| Ярлык | `~/.local/share/applications/linux-arizona-rp.desktop` |

Поддерживаются XDG_DATA_HOME, XDG_STATE_HOME, XDG_CACHE_HOME и XDG_CONFIG_HOME. Для запуска копии инструментов сохраняются отдельно: перемещение или удаление скачанного репозитория не должно сломать команду `arizona`.

## Возврат изменений

Путь плана восстановления печатается при установке. Закройте Faugus и приложения Wine и подставьте этот путь:

```bash
bash install.sh --restore "$HOME/.local/state/linux-arizona-rp/backups/ДАТА/restore.json"
```

Это **возврат изменённых файлов**, а не полное удаление установки: системные пакеты, Flatpak, скачанные компоненты и игровой префикс остаются. Снимок включает файлы реестра префикса, установленные нами шрифты, ярлык, инструменты и список игр Faugus. Если после снимка вы добавили другие игры или поменяли реестр, полный возврат вернёт эти файлы к прежнему состоянию; сначала сохраните новые данные.

Точечный откат служебных файлов `:Zone.Identifier` описан в [инструкции по шрифтам](fonts.md). Отдельный откат HUD: используйте напечатанную резервную копию `games.json`; учитывайте, что она содержит все записи Faugus на момент настройки.
