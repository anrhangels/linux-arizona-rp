# Установка по шагам

Эта страница для тех, кто впервые запускает Arizona RP на Linux. Все команды вводятся в терминале — программе, в которой можно выполнять действия текстовыми командами.

## Перед началом

Подготовьте интернет, место для игры и установленный драйвер видеокарты с поддержкой Vulkan. Нужен обычный 64-битный ПК или ноутбук с Linux. [Какие системы предусмотрены →](distributions.md)

Закройте Faugus, лаунчеры и игры, запущенные через Wine или Proton. Установщик попросит закрыть их, если они работают: ему нужно настроить файлы игры и шрифты.

## 1. Скачайте папку с установщиком

Откройте [ссылку на ZIP-архив](https://github.com/anrhangels/linux-arizona-rp/archive/refs/heads/main.zip). Можно также нажать на GitHub **Code → Download ZIP**.

Распакуйте архив через файловый менеджер. Затем откройте распакованную папку: в ней должны лежать `install.sh`, `README.md` и папки `scripts`, `docs`, `assets`. Архив перед запуском нужно именно распаковать.

## Как открыть терминал в нужной папке

Самый простой способ: откройте папку с `install.sh`, нажмите правой кнопкой на свободном месте и найдите пункт **«Открыть в терминале»**.

Если пункта нет:

1. Откройте терминал из меню приложений.
2. Скопируйте полный путь папки из адресной строки файлового менеджера.
3. Введите `cd `, затем вставьте путь в кавычках и нажмите Enter.

Например, если распакованная папка находится в русской папке загрузок:

```bash
cd "$HOME/Загрузки/linux-arizona-rp-main"
```

В английской папке загрузок пример будет таким:

```bash
cd "$HOME/Downloads/linux-arizona-rp-main"
```

Используйте только тот путь, где действительно лежит ваша папка. Её название после распаковки может отличаться.

Проверьте содержимое командой:

```bash
ls
```

**Ожидаемый результат:** среди файлов вы видите `install.sh`. Если его нет, нужно перейти в другую папку.

## 2. Запустите установщик

```bash
bash install.sh
```

Выполняйте команду как есть, без добавления `sudo` в начало. Установщик сам запросит права администратора для нужных системных программ.

Сначала появится список действий. Чтобы согласиться, введите `y` и нажмите Enter. Для отказа нажмите Enter, не вводя ничего.

Если система попросит пароль, введите пароль своего пользователя Linux. Символы при вводе могут не появляться: ни буквы, ни звёздочки. Это нормально. Закончив ввод, нажмите Enter.

**Ожидаемый результат:** начинается установка программ и загрузка компонентов. На первом запуске это может занять время. Пока скачивание идёт, не закрывайте терминал.

Если хотите сначала только посмотреть список действий:

```bash
bash install.sh --plan
```

Эта команда ничего не устанавливает. Для самой установки после неё всё равно нужно выполнить `bash install.sh`.

## 3. Дождитесь окончания настройки

Установщик сам подготовит программы для запуска игры, скачает официальный лаунчер Arizona и настроит шрифты. Основные компоненты объяснены в [словаре](glossary.md); учить их названия для установки не требуется.

Если после установки сам открылся лаунчер Arizona, **закройте его**, чтобы скрипт завершил оставшиеся шаги.

**Ожидаемый результат:** в терминале появится сообщение «Готово» и команда запуска. Если вместо этого появилась ошибка, откройте [помощь по симптомам](troubleshooting.md). Сообщение о завершении одного скачивания ещё не означает завершение всей установки.

## Первый вход

Найдите **Arizona RP** в меню приложений. Если ярлык пока не появился, запустите из терминала:

```bash
~/.local/bin/arizona
```

В открывшемся официальном лаунчере:

1. Выберите **Arizona RP**.
2. Дождитесь загрузки игровых файлов.
3. Выберите сервер.
4. Войдите в аккаунт или зарегистрируйтесь.
5. Запустите игру. Для управления персонажем переключитесь на английскую раскладку.

**Установка закончена, когда вы действительно вошли в игру.** Открытый лаунчер — промежуточный результат. Проверьте передвижение, чат и повторный запуск после закрытия игры.

Если форма регистрации принимает текст, но не отправляет данные, попробуйте отключить «Новую авторизацию» в настройках лаунчера. Этот способ помог в нашей проверке.

## Как запускать в следующий раз

Используйте ярлык **Arizona RP** или ту же команду:

```bash
~/.local/bin/arizona
```

Установщик повторно запускать перед каждой игрой не нужно. Если команда `arizona` без полного пути работает у вас в терминале, можно пользоваться ею. Если появляется «команда не найдена», используйте полный вариант выше.

Папку скачанного репозитория после успешной настройки можно переместить: необходимые для запуска инструменты установщик сохраняет отдельно. Не удаляйте папку самой игры.

## Если лаунчер уже скачан

Обычная установка сама скачает официальный файл — искать его заранее не требуется. Эта возможность нужна, если вы уже скачали установщик с [официального сайта Arizona](https://arizona-rp.com/) или автоматическое скачивание не прошло.

Для файла в папке загрузок:

```bash
bash install.sh --installer auto
```

Скрипт ищет Arizona EXE в системной папке загрузок, `Downloads` и `Загрузки`, затем выбирает самый свежий по времени изменения. Если скачано несколько файлов и вы хотите выбрать конкретный, укажите полный путь:

```bash
bash install.sh --installer "$HOME/Загрузки/Arizona-Games-Launcher.exe"
```

Замените путь и имя на свои. Кавычки сохраняйте, особенно если в пути есть пробелы.

## Возврат изменений

Во время установки скрипт сохраняет копии изменяемых файлов. Если нужно вернуть настройки, сначала откройте [инструкцию по восстановлению](advanced.md#восстановление-файлов): там объяснено, какие файлы вернутся и какие изменения могли появиться после создания копии.

**Восстановление настроек не удаляет игру и установленные программы.** Для обычного повторного запуска оно не требуется.

Для параметров установки, своего расположения игры и уже настроенного Faugus используйте [техническое руководство](advanced.md).
